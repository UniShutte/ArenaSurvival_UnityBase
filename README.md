# Arena Survival

Стартовый проект перед лабораторной работой №4 по дисциплине «Основы работы с Unity».
Содержит результаты ЛР1–ЛР3: окружение, FPS-персонажа, стрельбу, события здоровья и пул снарядов.

## Environment

- Unity Editor: **6000.3.24f1**.
- Universal Render Pipeline: **17.3.0**.
- Input System: **1.20.0**; ввод пока читается через `Keyboard.current` и `Mouse.current`.
- Cinemachine **2.10.7** уже установлен, но подключение камеры отложено до ЛР4.
- Unity Test Framework: **1.6.0**.
- Целевая платформа: Windows x64.

Не обновляйте Editor и пакеты при открытии проекта. Версии зафиксированы в
`ProjectSettings/ProjectVersion.txt`, `Packages/manifest.json` и `Packages/packages-lock.json`.

## Первый запуск после клонирования

1. Установите Unity **6000.3.24f1** через Unity Hub.
2. Клонируйте репозиторий через Fork или Git. После слияния подготовительной ветки используйте `master`.
3. В Unity Hub выберите **Add project from disk** и папку с `Assets`, `Packages`, `ProjectSettings`.
4. Дождитесь восстановления пакетов и импорта ресурсов. Первый запуск требует доступа к реестру пакетов Unity.
5. Откройте **`Assets/_Project/Scenes/Arena_01.unity`**.
6. Нажмите Play и щёлкните по Game View для захвата курсора.

Все необходимые игровые ресурсы находятся в репозитории; отдельный импорт Asset Store-пакетов
для запуска этого состояния проекта не требуется. `Library`, `Temp` и `Logs` создаются локально.

`Arena_Environment_Test` сохранена как вспомогательная сцена и не включена в сборку.
`SampleScene` относится к исходному шаблону, а не к учебному игровому сценарию.
В Build Profiles основной сценой уже указана `Arena_01`.

## Controls

WASD — движение  
Left Shift — ускорение  
Space — прыжок  
Mouse — осмотр  
Escape — освободить курсор  
Left Mouse Button — одиночный выстрел; при свободном курсоре также захватывает курсор

Ходьба: 5 ед./с; спринт: 8 ед./с; высота прыжка: 1.5 ед.
Оружие наносит 25 урона за попадание. Для целей с 50/100/150/200 HP нужны
соответственно 2/4/6/8 попаданий. При нулевом здоровье цель отключается.
Здоровье выводится в Console; HUD и Cinemachine будут добавлены в ЛР4.
При падении ниже Y = -10 персонаж возвращается к старту.

## Проверка перед занятием

1. Пройдите от точки появления по Terrain к целям; проверьте WASD, Shift, Space и обзор.
2. Убедитесь, что горизонт не наклонён, игрок не проходит через крупные препятствия.
3. Поразите все четыре цели: здоровье уменьшается, при нуле цель исчезает.
4. Для проверки пула временно включите `Log Pool Operations` у `Gameplay/Combat/ProjectilePool`.
   Повторяющиеся Instance ID подтверждают повторное использование; после проверки отключите логирование.
5. Проверьте возврат после падения и отсутствие ошибок в Console.

Автоматические проверки: **Window → General → Test Runner → PlayMode → Run All**.
Тесты `ArenaSurvival.PlayModeTests` загружают `Arena_01`, проверяют физические попадания,
смерть целей, подписки, повторное использование снарядов, таймер жизни, движение и возврат.
Во время тестов не управляйте персонажем вручную.

## Работа студентов

После получения проекта создайте собственную ветку, например `lab/04-hud-and-feedback`.
Сохраняйте осмысленные коммиты и отправляйте ветку в свой репозиторий согласно правилам курса.
**Git-теги для лабораторных не используются.** Подготовительная ветка преподавателя
`fix/lab3-ready-for-lab4` предназначена для последующего слияния в `master`.

## Структура

- `Assets/_Project/Scripts`: учебные компоненты, сборка `ArenaSurvival.Core`.
- `Assets/_Project/Prefabs`: игрок, цели, снаряд и окружение.
- `Assets/_Project/Scenes/Arena_01.unity`: основная сцена.
- `Assets/_Project/Settings/Terrain`: данные Terrain и четыре слоя поверхности.
- `Assets/_Project/Tests`: Play Mode-проверки; не входят в обычную игровую сборку.
- `Assets/_Project/Documentation/ASSET_SOURCES.md`: инвентаризация сторонних ресурсов.

Перед распространением исходных сторонних ресурсов преподаватель должен подтвердить
их источники и условия использования: список неподтверждённых сведений указан в `ASSET_SOURCES.md`.
