# Arena Survival

Учебный проект по дисциплине, связанной с разработкой игр на Unity.

## Environment

Unity Editor: укажите точную версию  
Render Pipeline: Universal Render Pipeline  
Input: Input System  
Target Platform: Windows x64

## Controls

WASD — движение  
Left Shift — ускорение  
Space — прыжок  
Mouse — осмотр  
Escape — освободить курсор  
Left Mouse Button — повторно захватить курсор
